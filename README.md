# ⚛️ Final-QSV (Quantum State Visualizer)

Final-QSV is an interactive quantum state visualization platform developed using Python to simplify complex quantum mechanics concepts. The application enables users to explore qubit states, superposition, probability amplitudes, and quantum state transformations through dynamic and intuitive visual representations.

This project demonstrates scientific visualization, mathematical modeling, and Python programming skills by presenting abstract quantum computing concepts in an interactive and easy-to-understand format.

---

## 🚀 Features

- ⚛️ Interactive Quantum State Visualization
- 🔵 Bloch Sphere Representation
- 📊 Probability Amplitude Visualization
- 🔄 Quantum State Transformations
- 📈 Dynamic Graphical Simulations
- 🎯 Educational Interface for Learning Quantum Computing
- 🖥️ User-Friendly Visualization
- 📐 Mathematical Representation of Qubit States

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Ishwaryambika92/Final-QSV.git
```

Navigate to the project directory

```bash
cd Final-QSV
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python main.py
```
